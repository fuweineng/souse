Packages

各平台安装包

下载后解包即用，含程序、管理台静态资源、抄表识别模型与结算单字体。校验文件一并提供，安装脚本会自动核对。

国内下载慢？ 脚本在 GitHub 直连 60 秒没下完时会自动切到加速镜像，下载完仍校验 SHA256；也可手动指定 SOUSE_MIRROR=... 或加 --mirror-only。
What you get

装完就有的四件事

  1. 常驻服务systemd 托管，崩溃自动重启，开机自启，不用管着它。
  2. 自动备份每天 00 / 06 / 12 / 18 点各备一份数据库，保留 30 天，带 SHA256。
  3. 一条命令管全套sousectl start | stop | status | logs | backup | restore | update。
  4. 外网能进配一条 Cloudflare 隧道指向 127.0.0.1:8080，不开放任何入站端口。
Manual install

不想跑脚本，手动也行

manual
# 1. 解包到 /opt/souse $ sudo mkdir -p /opt/souse && sudo tar -xzf \ souse-linux-amd64.tar.gz -C /opt/souse --strip-components=1 # 2. 用自带的示例配置起服务（第一个参数就是配置文件） $ cd /opt/souse $ sudo cp config.example.yaml config.yaml $ sudo ./610souse config.yaml ✓ 初始管理员密码会打印在日志里
手动方式不会自动注册服务、备份和自启；要这些效果就跑安装脚本，或参考 仓库说明自己配 systemd。
Requirements

跑它需要什么

Linux x86_64 Debian 12 / Ubuntu 22.04+ 内存 ≥ 1 GB 磁盘 ≥ 5 GB 端口 8080（管理台/API） 端口 8090（MCP）
macOS / Windows 暂无安装包。本版只发布 Linux x86_64 二进制；其它平台需要从源码自行编译，下载页不会给你一个装不上的包。
