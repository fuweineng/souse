Quick Start

三行命令，启动一栋楼

容器起来就是完整系统，首次访问跟随 6 步向导完成初始化。

bash — deploy
# 1. 环境文件（只需填管理员密码） $ cp .env.example .env # 2. 启动（前端后端现场编译） $ docker compose up -d --build ✓ souse started → http://<主机>:8080 # 3. 打开管理台，跟随向导 $ open http://<主机>:8080 # 楼栋 → 收款码 → 水电表 → 路由 → 门禁 → 完成
部署形态：任意 Linux 主机、PVE LXC 或 NAS 均可；外网访问用 Cloudflare Tunnel，数据每 6 小时热备到 backups/，健康探测失败自动重启。
  1. 硬件凭据只填一次路由、门禁、抄表的地址与账号集中在「系统设置」，保存即热生效，换设备不用重启。
  2. 规则跑在后台账单放出、催缴、逾期断网断门由自动化引擎按时执行，支持干跑预演。
  3. 住户自助小程序里开门、充值、看账单，管理员只处理异常。
  4. AI 接管重复劳动“看看今天谁欠费、把 A-202 断网”——一句话完成。
