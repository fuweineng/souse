Quick Start

三行命令启动一栋楼

不需要装数据库、不需要编排中间件，容器起来就是完整系统。

# 1. 准备环境文件（只需填管理员密码）
cp .env.example .env

# 2. 启动（前端后端现场编译）
docker compose up -d --build

# 3. 打开管理台，跟随 6 步向导
http://<主机>:8080
# 楼栋房间 → 收款码 → 水电表 → 路由 → 门禁 → 完成
部署形态：任意 Linux 主机、PVE LXC 容器或 NAS 均可；外网访问用 Cloudflare Tunnel， 数据库每 6 小时热备到本地 backups/，健康探测失败自动重启。
  1. 填一次硬件凭据。路由、门禁、抄表的地址与账号在「系统设置」里集中管理，保存即热生效。
  2. 规则跑在后台。账单放出、催缴、逾期断网断门由自动化引擎按时执行，支持干跑预演。
  3. 住户自助。小程序里开门、充值、看账单，管理员只处理异常。
  4. AI 接管重复劳动。MCP 工具暴露给 Agent，"看看今天谁欠费、把 7-302 断网"一句话完成。
