部署

装在自己的机器上

下载安装包，双击，跟着向导走。程序、管理台、自动备份与开机自启一次装好，装完直接给出地址和初始密码。

Windows

下载后解压，双击「双击安装.cmd」，在向导里选目录和端口。

下载 Windows 安装器

首次运行若提示「已保护你的电脑」：更多信息 → 仍要运行。

macOS

下载后解压，按住 Control 点「Souse 安装器.command」→ 打开。

下载 macOS 安装包

装到 ~/Library/Application Support/souse，不需要 Apple 开发者签名。

Linux / 小主机

服务器或 Linux 小主机用一条命令装好，由 systemd 托管。

curl -fsSL https://souse.dpxon.com/install.sh | sudo sh

服务：systemctl status souse（详见下载页）。

  1. 设备账号只填一次路由、门禁、水表的地址与账号都在「系统设置」里，改完立即生效，无需重启。
  2. 6 步向导配齐一栋楼楼栋、收款码、水电表、路由、门禁，按向导走完即可用。
  3. 自动备份与自启每 6 小时备份一份，进程异常自动重启；外网访问走一条 Cloudflare 隧道。
对比

与常见做法比

只比每天都会碰到的事：费用、欠费处理、住户入口、数据归属。

Excel + 微信群公寓 SaaSSouse
费用免费，但对账靠人订阅费，多数绑自家硬件免费自托管
欠费处理人工催缴断电或锁门（绑硬件）断网与门禁，用现有路由 + 海康
住户入口群里口头通知装 App 或关注公众号房间二维码，零安装
数据与硬件在自己手里数据在平台云，硬件绑定数据在自己的机器上，不卖硬件、不经手租金

差别不在功能条数，而在商业结构：不卖硬件、不经手租金、数据留在你的机器上——这三条，平台型 SaaS 无法跟进。

问题

常见问题

收费吗？

不收。免费自托管，装在自己的机器上，没有订阅费；不卖硬件，也不经手租金。

需要先买硬件吗？

不需要。已有设备能接就接：爱快、MikroTik 路由，海康门禁，大华录像机，水电表。没有门禁也能用：收租、账单、合同、押金、住户手机页一个不少。

数据放在哪里？

在你自己的机器上：家里的小主机、虚拟机或云服务器。系统每 6 小时自动备份一份，平台拿不到你的数据。

住户需要装 App 吗？

不需要。房间贴一张二维码，微信扫码进入网页版，查账单、开门、充值、报修都在里面。

怎么部署？升级会丢数据吗？

Linux 一条命令（install.sh），需要 systemd；小主机、虚拟机、云服务器都行。升级只更换程序版本，数据留在原处，另有每 6 小时的备份兜底。
