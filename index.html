Quick Start

三行命令，启动一栋楼

想装在自己电脑或 NAS 上，让会弄电脑的朋友跑三行命令就行。打开页面跟着 6 步向导走，把楼栋、收款码、水电表、路由、门禁设一遍就能用。

bash — deploy
# 1. 配置（只需设一个管理员密码） $ cp .env.example .env # 2. 启动（自动装好管理台和后台） $ docker compose up -d --build ✓ 启动完成 → http://<主机>:8080 # 3. 打开管理台，跟随向导 $ open http://<主机>:8080 # 楼栋 → 收款码 → 水电表 → 路由 → 门禁 → 完成
装在哪：家里的电脑、NAS、云服务器都行；外网访问配一条 Cloudflare 隧道，数据每 6 小时自动备份，出故障自动重启。
  1. 设备账号只填一次路由、门禁、水表的地址账号都在「系统设置」里，改完马上生效，换设备不用重启。
  2. 规则跑在后台到点发账单、催缴、断网，都按你设的规则自动执行，启用前可以先模拟跑一遍。
  3. 住户能自己办的不找你手机页里开门、充值、看账单，你只管处理出问题的。
  4. 懒得点页面就打字问“今天谁欠费”“把 A-202 断网”，它自己查、自己办。

FAQ

你大概会问这几个

都是被问过的，直说。

要收费吗？

不收。开源免费，装在自己的机器上，没有订阅费。我们不卖硬件，也不经手你的租金。

需要买什么硬件？

不强制买任何东西。你现有的能接就接：爱快、MikroTik 路由器，海康门禁，大华录像机，水电表都能配。以后想接再接，不接也能用。

没有海康门禁能用吗？

能。纯软件模式照样用：收租、账单、合同、押金、住户手机页这些一个不少，门禁和网络控制等你有设备了再开。

数据放哪？

在你自己机器上——家里电脑、NAS 或者你自己的云服务器。平台拿不到你的数据，系统每 6 小时自动备份一份。

住户要装 App 吗？

不用。房间贴一张二维码，微信扫一扫就进住户手机页（网页版，不用下载 App），查账单、手机开门、充值、报修都在里面。

升级会丢数据吗？

不会。升级只是换程序版本，数据还在原来的地方；另外每 6 小时有一份自动备份兜底。

支持哪些部署方式？

Docker Compose 三行命令就能起来，电脑、NAS、云服务器都行；外网远程访问走一条 Cloudflare 隧道。装好后页面里有 6 步向导，一步步把楼栋、收款码、水电表、路由、门禁配齐。
